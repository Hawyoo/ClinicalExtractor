# 固定模板行对齐

用户选择具体报告模板后，将模板名称、标准单位、参考范围当作固定字段联合识别行名；报告结果独立提取，不能作为匹配依据。

1. 计算每个OCR行与每个模板项目的候选关系，包含名称/别名相似度、参考范围是否一致、单位相似度。
2. 已明确出现的嗜酸/嗜碱、计数/百分比冲突会排除候选；明确参考范围与模板冲突则提示核对。
3. 优先锁定高可靠锚点；剩余项目以一对一约束重新比较。每次自动对应需要候选间、竞争行间有足够区分。
4. 即使名称损坏，参考范围与单位可联合确认项目。仅有通用名称、只有行顺序、或者只剩一个模板项目，不足以确认。
5. 对应后使用标准中文项目名；参考范围和项目联合确认时使用模板固定单位，并保存原单位。保留OCR原行、候选证据与校正日志，不改数值。
6. 缺失项目不补值；重复与冲突项目保留待核对。界面的人工“确认”状态仍由用户操作。

血常规模板包含原xls的24项参考范围。这些范围只针对用户选择的这份固定模板，不作为适用于所有人群的通用诊断阈值。

AI阶段接收同一模板定义和整表对齐要求，并输出原始行名、标准行名和理由；证据仍需逐字对应OCR原文。纯文本AI并未直接查看原始图片，字形推断属于结合上下文的纠错，不是重新做视觉识别。
