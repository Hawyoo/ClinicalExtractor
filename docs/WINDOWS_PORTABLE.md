# ClinicalExtractor Windows 便携版

双击 `ClinicalExtractor.exe`。启动窗口会显示当前状态，完成后自动打开浏览器；可用窗口中的按钮重新打开浏览器或关闭程序。`Start-ClinicalExtractor.bat` 仅保留为兼容入口。

- `data`：SQLite 数据库、上传报告和导出文件。
- `models\paddlex-cache`：随便携版一并打包的 PP-StructureV3 模型缓存；正常使用时无需首次联网下载。只有重新构建便携版时，构建电脑需要联网下载或更新模型。
- `logs\launcher.log`：启动与运行日志。
- `clinical-extractor.ico`：桌面程序与启动窗口使用的图标。

Ollama 不打包在便携版中；需要处理长文本报告时，请在 Windows 上安装并运行 Ollama，并准备设置页中指定的模型。

## 两台电脑分工

可在没有 Ollama 的电脑上导入报告后，点击“仅 OCR 全部未处理报告”。这会把 OCR 原文、版面结果、自动识别的日期和（表格式报告的）表格结果保存到 `data` 中；长文本报告状态会显示为“OCR已完成”。

如果目标电脑的 `data` 为空，关闭程序后直接复制整个 `data` 文件夹也可以。在目标电脑已有数据时，请在第一台电脑点击“导出 OCR 数据包”，得到专用的 `.ceocr` 文件；再在第二台电脑点击“导入 OCR 数据包”。

每份报告带有稳定的跨机器标识。因此第二次或后续导入时，软件会先显示冲突清单：患者 ID、文件名、本机状态、数据包状态，并由你逐条勾选是否覆盖。默认不勾选，即保留处理机已有的大模型结果；数据包中的新报告自动加入。若勾选，则用新包中的该报告及其抽取结果更新本机版本。这样可以反复从 OCR 机导出全量包，而不会误覆盖已处理患者。

随后安装并启动 Ollama，打开对应长文本报告，点击“继续大模型抽取”即可，无需再做 OCR，也不依赖第一台电脑的原始绝对路径。

`data` 是一个完整工作批次，包含：

- `clinical_extractor.sqlite3`：报告、OCR 文本、抽取结果和审核状态；
- `uploads`：原始报告副本；
- `exports`：导出的 CSV / Excel；
- `settings.json`：本机设置（复制后可按第二台电脑的 Ollama 地址和模型重新保存）。

不要把两个已有的 `data` 文件夹直接用资源管理器“合并”：SQLite 数据库不能安全地按文件合并，可能造成报告编号和结果关联冲突。应使用 `.ceocr` 专用数据包汇总到处理机；全部完成并审核后，使用首页已有的 CSV / Excel 导出作为最终结果文件。
