# ClinicalExtractor 便携版

双击 `ClinicalExtractor.exe`。启动窗口就绪后会打开默认浏览器，可从网页或启动窗口退出。

## 保存的数据

`data` 包含数据库、导入文件、运行设置及深色模式/排序偏好。移动软件时保留整个目录。Ollama 不随包携带，请在设置中填写服务地址和已经准备好的模型。

各项目保存在 `data/projects` 的独立文件夹内，包含 `project.json`、数据库、`uploads` 和 `exports`。顶部“当前项目”可切换，“项目管理”可新建或通过文件夹路径打开已有项目。报告、队列与导出按项目隔离；模型和运行设置共用。队列完成后才能切换。

首次启动先提示创建或打开项目，不自动创建默认项目。需要旧版数据时，在创建时勾选导入，保留审核状态及原文件备份。项目文件夹消失后自动清理失效登记并返回选择页。项目管理可删除当前项目，文件夹移入根目录 `DELETE`，可恢复。跨项目合并：在源项目导出数据包，切换目标项目后导入。整个项目文件夹也可在关闭程序后复制到另一台电脑，再通过“打开已有项目”登记。

## 处理报告

导入后点击“全部运行”。无可用 Ollama 时只执行 OCR；连接可用模型后可逐报告运行 AI。结果在“抽取确认”中审核，红色“AI重新配对”表示原文对应关系曾由 AI 调整，需要核对。清晰的原图行对应不允许 AI 改选，不会为落入正常范围而移动结果。

顶部“导出”下载当前项目的 CSV，文件名带导出时间；“数据包迁移”默认折叠，点击后打包或导入 `.ceocr`。仅导入原图尚未 OCR 时也能迁移；新报告追加，重复报告默认跳过，明确勾选才覆盖对应报告。

随包模型仅包括 PP-OCRv5 检测、识别和 SLANet_plus 回退，正常 OCR 无需联网下载。软件日志位于 `logs`。

## 编辑检验模板

审核页展开“新增 / 修改检验模板”。可修改展示名称、兼容名称、CSV 英文缩写、参考范围（每行一个）、主单位及兼容单位，并从实时分区下拉框选择分类，或点击“新建分类”。保存后模板立即用于后续匹配；不会改写报告数值或重置审核状态。

自定义模板对所有项目共用，位于 `data/table_templates/custom.yaml`，历史备份在 `history` 子目录中，移动软件或更新便携版时随整个 `data` 保留。分区只用于整理，不需要为每张图片选择模板。 英文全称可填写在项目兼容名称中，不另设英文名称字段。
