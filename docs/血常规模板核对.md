# 血常规模板核对

来源：用户提供的 D:/Downloads/血常规.xls，sheet0，共24个项目。原文件未修改。

| 位置           | 原文                      | 核对意见                                          |
| ------------ | ----------------------- | --------------------------------------------- |
| B22（第21项）    | 血小板比客                   | 错别字，应为“血小板比容”，常见别名“血小板压积”，PCT                 |
| F4（第3项）      | 9/L                     | 血红蛋白浓度的单位应为 g/L                               |
| F17、F20、F25  | fl                      | 单位书写统一为 fL                                    |
| F19          | g/l                     | 单位书写统一为 g/L                                   |
| B18          | 平均RBC血红蛋白含量             | 建议统一为“平均红细胞血红蛋白含量”（MCH）；原称呼作为别名保留             |
| B19          | 平均RBC血红蛋白浓度             | 建议统一为“平均红细胞血红蛋白浓度”（MCHC）；原称呼作为别名保留            |
| F23（第22项PDW） | %                       | 需核对原始仪器报告。部分仪器使用fL，不能仅凭项目名称统一替换，也不能在%与fL间直接换算 |
| E3、E4、E16    | 4.30–5.80、130–175、40–50 | 对应成人男性的RBC、Hb、HCT参考范围，不能给所有患者固定套用             |

其余项目名称未见明确错别字。“嗜酸粒细胞/嗜碱粒细胞”与“嗜酸性粒细胞/嗜碱性粒细胞”作为同义称呼处理。MPV、P-LCR、PCT、PDW和RDW等的参考范围需保留报告单原值，不能视为通用固定阈值。

## 软件模板

模板位于 profiles/table_templates/lab_test_template.yaml，其中血常规部分覆盖原表24项。用于规范项目名称与英文缩写，区分百分比与绝对计数。模板不提供患者数值，不填充缺失项目，不以示例参考范围覆盖原报告；单位保留OCR原文，预期单位仅作为核对元数据。

导入多张图片时，每张可独立选择“表格式报告 → 血常规”。当前采用精确别名匹配，未匹配项目保留原文并记录核对提示。
